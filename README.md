## Теоретическая справка

### Теорема Котельникова

Непрерывный сигнал с ограниченным спектром можно точно восстановить по его дискретным отсчётам, если частота дискретизации $f_s$ превышает максимальную частоту в спектре сигнала $f_{\max}$ минимум в два раза:

$$
f_s > 2 \cdot f_{\max}
$$

### Дискретное преобразование Фурье (ДПФ)

Переход от временного представления сигнала к частотному осуществляется через прямое ДПФ:

$$
F(x) = \sum_{n=0}^{N-1} f(n) \cdot e^{-j 2\pi \frac{x \cdot n}{N}}
$$

где:

- $N$ - количество отсчётов,
- $f(n)$ - дискретный сигнал во временной области,
- $F(x)$ - спектр.

Сложность алгоритма: $O(N^2)$. Для ускорения используется **Быстрое преобразование Фурье (БПФ)** со сложностью $O(N \log N)$.

### Квантование по уровню

АЦП с разрядностью $B$ бит представляет сигнал конечным числом уровней $L = 2^B$. Шаг квантования:

$$
\Delta = \frac{A_{\max} - A_{\min}}{L}
$$

## Рабочие формулы

Чувствительность приёмника и тепловой шум:

$$RxSens = NoiseFigure + ThermalNoise + RequiredSINR$$
$$ThermalNoise = -174 + 10 \cdot \log_{10}(BW)$$

Бюджеты каналов (из равенства уровня сигнала на приёмнике и чувствительности):

$$TxPower_{BS} - FeederLoss + AntGain_{BS} + MIMOGain - MAPL_{DL} - IM - PenetrationM = RxSens_{UE}$$
$$TxPower_{UE} - FeederLoss + AntGain_{BS} + MIMOGain - MAPL_{UL} - IM - PenetrationM = RxSens_{BS}$$

Модели распространения: UMiNLOS (помещения, формула 2.3 методички), COST231 Hata (макросоты, формулы 2.4-2.7), Walfish-Ikegami (городская grid-застройка, формулы 2.8-2.16). Радиус соты находится как точка пересечения кривой PL(d) с уровнями MAPL_UL и MAPL_DL; в расчёт берётся меньший из двух радиусов. Площадь сайта из трёх секторов: $S = 1.95 \cdot R^2$.

## Исходные данные

| Параметр | Значение |
| --- | --- |
| Номер группы | нечётный (схема рис. 4.5) |

## Краткая теория

**Псевдослучайные двоичные последовательности** - битовые последовательности (0/1 или $-1/+1$), которые выглядят случайными, но генерируются детерминированно через регистры сдвига с обратной связью (LFSR). Применяются для оценки BER, временной синхронизации (корреляционный пик отмечает начало слота/кадра) и расширения спектра (WCDMA).

**Три свойства «почти случайной» последовательности:**

1. **Сбалансированность (balance):** число единиц и нулей за период отличается не более чем на одну.
2. **Цикличность:** половину серий составляют циклы длиной 1, четверть - длиной 2, восьмую часть - длиной 3 и т.д.
3. **Корреляция:** автокорреляция близка к дельта-функции - пик $R(0) = +1$ при нулевом сдвиге и малые боковые значения при любых других.

**Автокорреляционная функция** по формуле (4.3) методички:

$$R_x(\tau) = \frac{N_{\text{совп}} - N_{\text{несовп}}}{p}$$

У идеальной m-последовательности боковые значения равны $-1/p$, пик при нуле равен $+1$. Коды Голда формируются суммированием по модулю 2 двух m-последовательностей и обладают хорошими взаимокорреляционными свойствами, что позволяет использовать их для разделения сот и секторов.

За 31 такт получена последовательность:

`1110000011111011001000110111101`

### Пункт 2. Автокорреляция при циклических сдвигах

Для каждого циклического сдвига $\tau \in [0, 30]$ исходная последовательность сравнивается со сдвинутой копией поэлементно, значение $R(\tau)$ вычисляется по формуле (4.3). Результат в таблице ниже: пик $R(0) = +1$ при нулевом сдвиге и малые боковые значения ($|R| \le 0.2903$) подтверждают дельта-образный характер АКФ.

### Пункт 4. Взаимная корреляция

Взаимная корреляция исходной и новой последовательностей при нулевом сдвиге: **0.1613**; максимальное значение по всем сдвигам - 0.4194 (сдвиг 16). Низкие значения взаимной корреляции подтверждают различимость двух последовательностей, что и требуется для разделения сот.
